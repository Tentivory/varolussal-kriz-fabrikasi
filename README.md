# 🤯 VAROLUŞSAL KRİZ FABRİKASI

## Bu Repo Nedir?

Bu, dünyanın **en ciddi**, **en abartılı**, **en anlamsız** ve **en işe yarayan** varoluşsal kriz üreticisidir.  
Gerçekten çalışır. Gerçekten kriz üretir. Gerçekten hiçbir şey değiştirmez.

### Nasıl Çalışır?

```bash
python kriz_fabrikasi.py
```

Bu komutu çalıştırdığınızda, evrenin en derin sorularından biri rastgele olarak size fırlatılır.  
Örneğin:

> Ya çay demlenirken ben de eriyorsam?

Bu soru sizi 3 saniye düşündürür, sonra unutursunuz. Bu da krizin bir parçasıdır.

## Neden Bu Proje Var?

Çünkü:
- İnsanlık yeterince kriz yaşamıyor.
- Herkes mutlu görünüyor, bu kabul edilemez.
- Kod yazmak özgürlüktür, kriz üretmek ise sanattır.
- Bu repo olmadan evren dengesiz kalırdı.

## Özellikler

- %100 gerçek Python.
- Sıfır bağımlılık (sadece zaman ve rastgelelik).
- Sonsuz kriz potansiyeli.
- Hiçbir şeyi çözmez, sadece sorar.
- Abartılı ciddiyet ile yazılmıştır.
